This release lets the agent limit the rate of what it sends to your computer, apart from the limit on what it receives.

## Why

On the server of the tests the two directions differ: files from a client arrive at 255 to 296 MB/s, and the server sends at most about 120 MB/s, on an outbound link that the other Remote Desktop sessions share. A send at the full rate fills that link, and about 2 % of its packets are sent again. The only limit so far, `directMaxMegabytesPerSecond`, slowed both directions.

## What happens now

- `sendMaxMegabytesPerSecond` in agent.json, or in the machine settings for every user, limits what the agent sends to a client, all the connections of a send together. 0, the default, changes nothing: `directMaxMegabytesPerSecond` then limits a send as before.
- The first line of the agent log gives the limit when it is set.

## Upgrade

Install the agent 0.9.2 to use the setting; the client is the one of 0.9.1 with a new version number. The protocol does not change.
