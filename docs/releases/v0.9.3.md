This release shows a loader as soon as UltimateRDP starts from a .bat file, a shortcut or the executable, until the program or the desktop is there.

## Why

A RemoteApp program takes about 12 seconds to show its window, a desktop about 7 seconds to log on, and nothing showed meanwhile but a small connecting window, and only for RemoteApp programs.

## What happens now

- A small window shows at once: the UltimateRDP mark, the name of the program or of the server, a moving bar, and the step: "Starting...", "Connecting to server.example.com...", "Opening the session...", "Starting Notepad...". After 10 seconds it says that the server takes longer than usual. Cancel stops the connection.
- It closes when the window of the program appears, when the desktop is logged on, or at any end before.
- It follows the light or dark theme of Windows and the scale of its monitor, never takes the keyboard, has no taskbar button, and hides while the certificate question, the password prompt or a message of UltimateRDP waits for an answer.
- A desktop that connects in the main window shows the loader over it.
- A second start handed to the running UltimateRDP shows the loader of the new session at once.
- `"loader": "off"` in client.json turns it off.

## Upgrade

Only the client changes. The protocol does not change.
