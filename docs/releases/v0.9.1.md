This release closes the small connecting window when the RemoteApp program appears, and closes an open menu of the main window at a click in the remote session.

## Why

The first real tests of 0.9.0 passed: a RemoteApp program opened from a shortcut showed only its own window, 12 seconds after the start instead of 19, a drop onto it was delivered, and the client exited by itself at the end of the session. Files sent from the session arrived at 115 to 134 MB/s over eight connections when the path from the server allowed it. Two things were left. The "Connecting to..." window stayed until the end of the session, because the control of this Windows version never raises the event that 0.9.0 waited for. And a menu of the main window stayed open when the next click went into the remote session, since the control takes the mouse in a window of a thread of its own.

## What happens now

- The connecting window closes as soon as a window of the program is found, by the event of the control or by the windows that the client finds in its own process.
- A click in the remote session closes the open menu of the main window, as a click anywhere else does.

## Upgrade

Install the client 0.9.1. The agent does not change: an agent 0.9.0 works with this client.
