This release lets one .bat file open a connection without a .rdp file, and writes such .bat files for you.

## Why

A .bat file per published program is how UltimateRDP reaches end users, so that starting a program stays one double click. Until now each .bat file needed a .rdp file written by hand beside it.

## What is new

- `UltimateRDP.exe` takes the connection on its command line: `--server`, `--port` (3389 by default), `--user`, `--domain`, `--remoteapp`, `--remoteapp-name`, `--remoteapp-args`, `--gateway`, and the display and redirection choices `--multimon`, `--scale`, `--windows-keys`, `--clipboard`, `--drives`, `--printers`, `--audio`. With a .rdp file, the options win over its keys. The README section "Launchers" lists them with the .rdp keys they set.
- `--help` or `/?` shows the list of the options in the language of the client.
- Every value is checked before anything opens. A wrong option shows a message that says which one and why, and nothing connects.
- There is no option for a password, on purpose: Windows uses the credential saved for the server, or asks for it.
- A second start hands its options to the UltimateRDP that already runs.
- File, Create a launcher (.bat)... writes a launcher: a .bat file with every option, or a .bat file and a .rdp file beside it, with UltimateRDP.exe at the path of the running program, next to the launcher, or at a path with variables such as `%LOCALAPPDATA%`. It fills itself from the active tab or from a .rdp file, shows the text of the .bat file as you type, and can save it, copy it, or test it.
- The values in a launcher are quoted so that cmd.exe gives them to UltimateRDP exactly and cannot run anything else. The tests check this with a model of cmd.exe and with cmd.exe itself, including hostile values.

## Not offered

Full screen at the start and a fixed desktop size: the client starts every session in its window and sizes the desktop to the window, as before.

## Upgrade

Only the client changes. The protocol does not change. Existing .bat files and .rdp files work as before.
