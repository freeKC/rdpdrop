This release gives the project its new name, UltimateRDP, adds a way to end the remote Windows session, and translates the client and the agent into six more languages.

The release contains two zips, each with one executable:

- `UltimateRDP-v0.3.0-win-x64.zip`: the client you run on your own computer.
- `UltimateRDP.Agent-v0.3.0-win-x64.zip`: the agent that runs in your session on the server.

The executables of this release are signed by APROGSYS.

## What changed since 0.2.1

**New name.** The project formerly called RdpDrop is now named UltimateRDP, and is published by APROGSYS (https://www.aprogsys.com/). The client is now `UltimateRDP.exe` and the agent `UltimateRDP.Agent.exe`. Settings and logs are now in `%LOCALAPPDATA%\UltimateRDP`, and the agent starts with the session through the registry `Run` value `UltimateRDP`. The virtual channel between the client and the agent has a new name too, so the 0.2.1 agent cannot answer this client. On the server, exit the 0.2.1 agent from its tray menu, then remove its `Run` value: run the old `RdpDrop.Agent.exe --uninstall`, from an elevated prompt if you installed it for all users, or delete the value `RdpDrop` by hand under `Software\Microsoft\Windows\CurrentVersion\Run` in `HKEY_CURRENT_USER` or `HKEY_LOCAL_MACHINE`. Then install the new agent as described below. The old folder `%LOCALAPPDATA%\RdpDrop` is no longer read: copy `client.json` or `agent.json` into the new folder to keep your settings, and delete the old folder when you no longer need its logs.

**Log off the remote session.** Quit, Close tab and Disconnect only disconnect, as the Microsoft client does, and your applications keep running on the server. The new entry File, Log off the remote session ends the Windows session. It asks for a confirmation, then the agent logs off the session. Applications with unsaved work ask what to do, in the session, as they do when you sign out from the Start menu.

**Languages.** The client and the agent now speak English, French, German, Spanish, Italian, Portuguese and Dutch. By default the client follows the display language of Windows. View, Language lets you choose another one, and the change applies at once. The choice is saved as `language` in `%LOCALAPPDATA%\UltimateRDP\client.json`. The tray menu of the agent follows the display language of Windows on the server. The logs stay in English.

**Protocol.** The hello of the client now carries `clientLanguage`, and the agent writes the messages it sends for the status bar in that language. Two messages are new: `logoff` and `logoffResult`. The client and the agent must both run 0.3.0.

**Settings files.** `client.json` and `agent.json` are now read even when an editor saved them with a byte order mark.

**A quiet agent for shared servers.** The agent can now start in every session of a Remote Desktop server, even when most users connect with the Microsoft client. In a session without an UltimateRDP client it shows nothing at all: no icon, no window, no message, even when something goes wrong. It waits with a few megabytes of memory and no measurable processor time, tries to open its channel every ten seconds and at once when a client connects, and writes at most one log line per hour. Its tray icon appears only while an UltimateRDP client is connected. The new `trayIcon` setting in `agent.json` changes this: `auto` (the default), `always`, or `never`. The agent survives disconnections and reconnections from either client, and exits at sign out without delaying it. The new `--status` option prints the version, the `Run` entries, the settings file and whether the agent runs in your session. `--install-all-users` can now be run again safely, removes the entry that `--install` left for your own account, and refuses an executable inside a user profile.

## Install

1. On the server, exit the 0.2.1 agent and remove its `Run` value, as described above. Unzip the new agent to a folder that every user can read, for example `C:\Program Files\UltimateRDP`.
2. Run `"C:\Program Files\UltimateRDP\UltimateRDP.Agent.exe" --install-all-users` from an elevated prompt, or `--install` for your own account only. In a session, `UltimateRDP.Agent.exe --status` shows what is installed and whether the agent runs.
3. On your computer, unzip the client anywhere and run `UltimateRDP.exe path\to\connection.rdp`. Wait for "Agent ready (v0.3.0)" in the status bar, then drag.

## Logs and feedback

Both logs are in `%LOCALAPPDATA%\UltimateRDP\logs`: `client-yyyyMMdd.log` on your computer, and `agent-yyyyMMdd.log` on the server. Please open an issue at https://github.com/freeKC/ultimaterdp/issues with both log files. I am also glad to hear about a translation that reads oddly in your language.

Thank you for trying UltimateRDP.
