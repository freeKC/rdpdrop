This release adds a way to end the remote Windows session, and translates RdpDrop into six more languages.

The release contains two zips, each with one executable:

- `RdpDrop.Client-v0.3.0-win-x64.zip`: the client you run on your own computer.
- `RdpDrop.Agent-v0.3.0-win-x64.zip`: the agent that runs in your session on the server.

The executables of this release are signed by APROGSYS.

## What changed since 0.2.1

**Log off the remote session.** Quit, Close tab and Disconnect only disconnect, as the Microsoft client does, and your applications keep running on the server. The new entry File, Log off the remote session ends the Windows session. It asks for a confirmation, then the agent logs off the session. Applications with unsaved work ask what to do, in the session, as they do when you sign out from the Start menu.

**Languages.** The client and the agent now speak English, French, German, Spanish, Italian, Portuguese and Dutch. By default the client follows the display language of Windows. View, Language lets you choose another one, and the change applies at once. The choice is saved as `language` in `%LOCALAPPDATA%\RdpDrop\client.json`. The tray menu of the agent follows the display language of Windows on the server. The logs stay in English.

**Protocol.** The hello of the client now carries `clientLanguage`, and the agent writes the messages it sends for the status bar in that language. Two messages are new: `logoff` and `logoffResult`. The client and the agent must both run 0.3.0.

**Settings files.** `client.json` and `agent.json` are now read even when an editor saved them with a byte order mark.

## Install

1. On the server, exit the running agent from its tray menu, then unzip the new agent over the old one, for example in `C:\Program Files\RdpDrop`.
2. Start it again, or run `"C:\Program Files\RdpDrop\RdpDrop.Agent.exe" --install-all-users` from an elevated prompt for a first install, or `--install` for your own account only.
3. On your computer, unzip the client anywhere and run `RdpDrop.Client.exe path\to\connection.rdp`. Wait for "Agent ready (v0.3.0)" in the status bar, then drag.

## Logs and feedback

Both logs are in `%LOCALAPPDATA%\RdpDrop\logs`: `client-yyyyMMdd.log` on your computer, and `agent-yyyyMMdd.log` on the server. Please open an issue at https://github.com/freeKC/rdpdrop/issues with both log files. I am also glad to hear about a translation that reads oddly in your language.

Thank you for trying RdpDrop.
