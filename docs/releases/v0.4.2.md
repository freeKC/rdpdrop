This release shows a window while large files are transferred to the session.

## Why

With 0.4.1 the fast transfer works: a file of 496 MB reached the session in 193 seconds. During those three minutes the only sign of it was a short text in the status bar. I took it for a transfer that had not started, dragged the file again, and the client refused the drag with the "not allowed" cursor, without saying why where I was looking.

## The transfer window

When a transfer starts, a small window "Transfer to the session" opens over the session. It shows:

- the name of the file being sent, with "file 2 of 3";
- a progress bar;
- the percentage, the rate and the time left, for example "42 %, 2.6 MB/s, 1 min 40 s left";
- the remote computer the files go to;
- a Cancel button, which does the same as Session, Cancel the transfer.

While the client lists the files, the bar runs without a value and the window says "Preparing...". If you drag more files over the session during the transfer, the window says "Wait for this transfer before dropping more files."

When the transfer succeeds, the window says how many files went through, in how long and how fast, then shows the result of the drop and closes by itself after three seconds. It stays while the mouse is over it. When the transfer fails or is cancelled, the window shows the reason in red and stays open until you click Close.

The window never takes the keyboard from the session. It stays open when you switch tabs, and closing the tab of the session cancels the transfer. The status bar keeps the same texts as before.

## Upgrade

Only the client changes. Install the 0.4.2 client; the agent can stay at 0.4.1 in the session, there is nothing new in it.
