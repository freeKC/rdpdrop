This release shows a progress window at every drop into the session.

## Why

With 0.4.1 the fast transfer works: a file of 496 MB reached the session in 193 seconds. During those three minutes the only sign of it was a short text in the status bar. I took it for a transfer that had not started, dragged the file again, and the client refused the drag with the "not allowed" cursor, without saying why where I was looking. A small drop gave no visible answer either, apart from the same status bar.

## The progress window

A progress window appears at every drop. As soon as you release the button over the session, a small window "Transfer to the session" opens over it, with the dropped items and the remote computer the files go to. It goes through three stages.

- Dropping: for an ordinary drop, a bar that runs without a value and "Dropping into the session...". For large files, the window says "Preparing..." while the client lists the files.
- Transferring, for large files only: the name of the file being sent with "file 2 of 3", a progress bar, and the percentage, the rate and the time left, for example "42 %, 2.6 MB/s, 1 min 40 s left". A Cancel button does the same as Session, Cancel the transfer. Once every file is in the session, the window says how many files went through, in how long and how fast, while the agent drops them.
- Result: "Dropped on ..." or "Nothing under the cursor accepted the files.", and the window closes by itself after three seconds. It stays while the mouse is over it. When the transfer or the drop fails, or is cancelled, the window shows the reason in red and stays open until you click Close.

If you drag more files over the session during a transfer, the window says "Wait for this transfer before dropping more files."

The window never takes the keyboard from the session. It stays open when you switch tabs, and closing the tab of the session cancels a transfer in progress. The status bar keeps the same texts as before.

## Upgrade

Only the client changes. Install the 0.4.2 client; the agent can stay at 0.4.1 in the session, there is nothing new in it.
